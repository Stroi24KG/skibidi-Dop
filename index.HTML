Какие данные собираются

При отправке заявки сайт может получать имя, номер телефона, Telegram, регион, выбранную услугу и описание задачи.

Зачем используются данные

Данные используются для связи с клиентом, уточнения задачи, расчёта стоимости и обработки заявки.

Заявки работников

Данные из формы «Нужны сварщики» используются для связи с кандидатами по вопросам работы.

Хранение

После подключения Apps Script данные могут передаваться в Google Sheets, Telegram и Bitrix24 в соответствии с настройками владельца сайта.

Удаление данных

Для запроса на удаление данных пользователь может обратиться по контактам, указанным на сайте.
